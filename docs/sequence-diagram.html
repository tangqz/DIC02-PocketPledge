System Execution Flow

Chat Agent vs. Vision Supervisor

sequenceDiagram
    autonumber
    
    %% 这里精简了参与者的名字，减少每列的宽度占用，从而让整体连线不那么稀疏
    participant U as User
    participant FE as Frontend
    participant WS as Gateway(WS)
    participant Media as Media AI
    participant CA as Chat Agent
    participant SA as Sys Agent
    participant VS as Supervisor
    participant Biz as Business

    rect rgb(240, 253, 244)
    Note over U,Biz: Phase 1 — Voice Session Start
    U->>FE: Speak
    FE->>WS: Audio Stream
    WS->>Media: ASR()
    Media-->>WS: Text
    WS-->>FE: Transcript
    
    WS->>CA: Chat Stream
    Note right of CA: Detect Start Intent
    CA-->>WS: Res + [SYS]
    WS-->>FE: Text Chunk
    
    WS->>WS: Pause Stream
    WS-->>FE: Req Visual Context
    FE->>FE: Capture Screen+Cam
    FE->>WS: Images
    
    WS->>SA: Parse: "start"
    SA->>Media: Eval Readiness
    Media-->>SA: Ready
    
    SA->>Biz: Start Session (25m)
    Biz->>Biz: Deduct Upfront
    Biz-->>SA: Session Ref
    
    SA-->>WS: [SYS: Started]
    WS->>CA: Inject Result
    CA-->>WS: Empathic Reply
    
    WS->>Media: TTS Synthesis
    Media-->>WS: Audio + Lip-Sync
    WS-->>FE: Play Audio & State: active
    end

    rect rgb(254, 242, 242)
    Note over U,Biz: Phase 2 — Active Supervision Loop
    loop Every N seconds
        FE->>WS: Screenshots
        WS->>VS: Evaluate Vision
        Note right of VS: Analysis
        VS-->>WS: {distracted, reason}
        
        alt Streak < 3
            WS-->>FE: Alert (severity)
        else Streak >= 3
            WS->>Biz: Penalty
            Biz->>Biz: Split (charity/reward)
            Biz-->>WS: New Balance
            WS-->>FE: Penalty UI
            WS->>CA: Prompt: "Distracted"
            CA-->>WS: Redirect Response
            WS-->>FE: Avatar Redirects User
        else OK
            WS->>WS: Reset Streak
        end
    end
    end

    rect rgb(255, 251, 235)
    Note over U,Biz: Phase 3 — Pause
    U->>FE: "Pause"
    FE->>WS: Input
    WS->>CA: Detect Pause
    CA-->>WS: Res + [SYS]
    WS->>SA: Parse: "pause"
    SA->>Biz: Record Request
    SA-->>WS: [SYS: Approved]
    
    WS-->>FE: State: paused
    WS->>CA: Inject Result
    CA-->>WS: "Sure..." → TTS
    WS-->>FE: Play Response
    end
